APLICAÇÃO

1. Copie os 5 arquivos novos para os caminhos indicados.
2. Substitua App.tsx, Header.tsx e Sidebar.tsx pelos arquivos deste pacote.
3. Adicione index.css.add.txt ao seu index.css atual.
4. Teste #/login e #/cadastro.
5. Rode npm run typecheck e npm run build.

DESIGN
- Login é propositalmente curto.
- Cadastro é maior e tem 4 passos.
- Primeiro pergunta se é Cliente ou Proprietário.
- Depois adapta o objetivo do perfil.
- Proprietário terá posteriormente fluxo próprio para publicação.
- A sidebar continua pública; recursos pessoais levam ao login.

SEGURANÇA
Esta versão é UI/UX. Não é autenticação real.
No backend: nunca guardar password em localStorage; validar tudo no servidor; usar sessão/token seguro; aplicar rate limiting; não confiar no role enviado pelo frontend.

PERFORMANCE
Nenhuma dependência nova. Framer Motion só no layout de autenticação. CSS para progress bar e interações simples. Sem imagens pesadas.
